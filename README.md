# Making Videos

Three independent agent skills for producing and sharing videos.

- **[make-clip](skills/make-clip/SKILL.md)** — Edit footage in FilmCraft, refine audio and color, add graphics, and review the finished export.
- **[make-youtube-thumbnail](skills/make-youtube-thumbnail/SKILL.md)** — Create or refine a compelling thumbnail using footage or visual references.
- **[upload-to-youtube](skills/upload-to-youtube/SKILL.md)** — Choose a channel and upload a finished video and thumbnail through YouTube Studio, or update an existing video’s details.

## Install

Install all three skills from GitHub:

```sh
npx skills add https://github.com/ioma8/making-videos
```

To install one skill, add `--skill` followed by its name. Creating a clip or thumbnail does not upload it.
