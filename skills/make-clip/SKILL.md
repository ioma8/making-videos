# Make a clip

For FilmCraft editing, read [references/filmcraft.md](references/filmcraft.md). Editing does not imply a YouTube upload.

1. Inspect the source, user instructions, destination, and existing project. Preserve source media and editable project assets.
2. Build and verify the requested edit. Inspect representative rendered frames including the beginning and ending; check the face, hands, instrument and overlays throughout. Confirm cut points against the actual gesture and preserve the performance.
3. Watch and listen to the entire exported file, including the final note and cut. For audio changes, compare the opening and a loud passage against the original at matched volume for noise, bass definition, clipping and changes in tone. Report any check that could not be performed.
4. Identify the current final export and editable project, distinguishing superseded versions. Reconcile artist, song, title and credits within the video; flag on-screen calls to action that lack a destination.

If a thumbnail is requested, use the `make-youtube-thumbnail` skill. If the user also requests a YouTube upload, use `upload-to-youtube` after the final export is verified.
