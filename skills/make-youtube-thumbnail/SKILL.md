# Captivating thumbnails

Use this workflow when a thumbnail is requested. Respect the user's chosen visual style and medium; generate imagery only when the task calls for it, using the available image-generation skill and tool.

1. When footage is available, inspect it and choose a sharp, representative frame with the performer, instrument or other subject clearly visible; extract it without overlays when possible. Otherwise inspect and use the supplied visual reference. Preserve recognizable features and the real subject rather than inventing a different person or performance.
2. Design a landscape 16:9 composition with a strong subject, uncluttered background, and a short text hierarchy readable at small sizes. In the successful bass thumbnail, the performer and black bass filled the frame, while large ivory serif text occupied the upper-left. Warm amber rim light, deep plum shadows and a dark background created contrast. This is a proven direction for that video, not a mandatory palette for every subject; adapt it to the footage and brief. Avoid adding unsupported logos or claims.
3. If using image generation, pass the inspected frame or supplied image as a reference. Specify the desired subject, composition, lighting, exact text, and elements to omit, including any existing score or captions. Check spelling and verify artist, song title and their relationship from the user's supplied facts; do not infer them from visual hierarchy. Inspect the generated result at thumbnail size for legibility, anatomy, instrument details and unwanted artifacts.
4. When the user approves the visual style but requests a small change, edit the approved image as the reference and explicitly preserve its composition, subject, lighting, palette and typography. Request only the intended change, verify the result, and retain the original as a separate version. The bass thumbnail was revised by adding the supplied song name while keeping the established editorial treatment.
5. Save the selected image to the project workspace. Check its aspect ratio, resolution, format and file size against current YouTube Studio upload requirements, and deliver the selected file; uploading is a separate task. Tell the user when the thumbnail is AI-generated or substantially altered.
